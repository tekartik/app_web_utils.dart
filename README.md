# app_web_utils.dart

Common web app utility projects (git packages, not on pub.dev):

* [`app_build`](packages/app_build) (`tekartik_app_web_build`): web app build helper.
* [`app_build_menu`](packages/app_build_menu) (`tekartik_app_web_build_menu`): build menu for a web app (dart, not flutter).
* [`mediapipe_js`](packages/mediapipe_js) (`tekartik_mediapipe_js`): experimental MediaPipe face landmarker bindings.
* [`sw_build`](packages/sw_build) (`tekartik_sw_build`): service worker build utils.
* [`sw_utils`](packages/sw_utils) (`tekartik_sw_utils`): service worker utils.
* [`three_js`](packages/three_js) (`tekartik_three_js`): experimental three.js bindings.
* [`web_splash`](packages/web_splash) (`tekartik_web_splash`): basic web splash support.
